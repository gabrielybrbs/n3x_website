# Documentação do projeto N3X

Registro da reformulação do site para a nova identidade visual (v1.0, setembro de 2026).

| Documento | Conteúdo |
| --- | --- |
| [auditoria.md](auditoria.md) | Diagnóstico do site anterior: problemas classificados, pontos positivos e comparação entre a identidade antiga e a nova. |
| [decisoes.md](decisoes.md) | Respostas da N3X às perguntas da auditoria. É a fonte de verdade para conteúdo, dados e escopo. |
| [plano-implementacao.md](plano-implementacao.md) | Arquivos, páginas, componentes, mudanças e ordem de execução. |

## Fluxo de trabalho adotado

Auditoria → perguntas → plano → aprovação → implementação.

Nenhum arquivo do site é alterado antes de o plano ser aprovado. Mudanças de escopo durante a implementação são registradas em `decisoes.md` antes de serem aplicadas.

## Referências de marca

Os materiais oficiais ficam em `brand/n3x-identidade/`, fora do que é publicado.

- `n3x-manual-da-marca.html` / `.pdf`: logo, cores, tipografia, grafismos, ícones e fotografia.
- `n3x-kit-digital.html` / `.pdf`: UI kit do site, redes sociais e assinatura de e-mail.
- `site/n3x-tokens.css`: tokens oficiais de cor, tipografia, espaçamento e forma.
